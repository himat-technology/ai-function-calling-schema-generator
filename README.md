## Features

- Function metadata & strict schema mode
- Dynamic parameter builder (string, number, integer, boolean, array, object)
- Enum, nullable, nested object, and array item support
- Live JSON Schema preview
- Provider converters: OpenAI, Claude, LangChain, JSON Schema
- Payload tester with AJV validation and line-by-line diagnostics
- TypeScript / Python SDK code generation
- Import OpenAI / Claude / JSON Schema
- Local draft save/restore via `localStorage`
- Production presets (web search, SQL, weather, email, code execution)

## Privacy

**100% Client-Side Privacy** — function definitions, schemas, and test payloads never leave your browser. No backend, no API keys, no analytics.
